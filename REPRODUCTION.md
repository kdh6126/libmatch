# Reproduction map

Every number in the article and its supplement is computed from a result table in `results/`, and each table is written by one script in `src/`. This file is generated from the source by `src/build_release.py`, so it cannot drift from the code.

The repository holds 266 scripts, most of them exploratory work that is not reported. Listed here are the 75 that the article depends on, found by starting from the figure and table generators and following which result tables each one reads.

## Order to run them in

The experiments are independent of one another except through the result tables they read, so the order below is the dependency order, not a required sequence. The matched libraries must exist first; building them needs the Absolut! binary and the per-antigen tables.

```
python src/exp68_more_matched.py      # matched libraries
python src/exp70_unmatched_seeds.py   # representation, before
python src/exp71_repr_many_antigens.py  # representation, after
python src/exp72_search_seeds.py      # search, 20 seeds
python src/exp73_why_residual.py      # what the residue tracks
python src/exp76_random_positions.py  # design-space dimension
python src/exp77_corrupt_conclusion.py  # integrity check
python src/fig_matching_limits.py     # Figures 3 and 4
python src/si_table_repr_antigens.py  # Supplementary tables
python src/si_order.py                # fix their numbering
python src/audit_new_claims.py manuscript/manuscript.tex
```

The last two lines need neither the Absolut! binary nor the 6.9-million-row tables. The result tables in `results/` and the LaTeX sources in `manuscript/` are enough to check that every number the article states matches the data it came from, which takes a few seconds.

## Environment this bundle was verified in

The bundle was copied to an empty directory outside the source repository, `requirements.txt` was installed into a fresh virtual environment, and the five checks below were run from there. The pinned versions are known to install and run on:

- Python 3.14.7
- Windows-11-10.0.26200-SP0

```
python -m venv venv && venv/Scripts/activate
pip install -r requirements.txt
python src/audit_new_claims.py    # every number against its table
python src/check_si_refs.py       # supplementary cross-references
python src/check_sources.py       # source integrity
python src/check_noise_axis.py    # the noise axis is not reported as zero
python libmatch/run_demo.py       # tool regression test
```

Pinning package versions does not pin the interpreter. On a much newer Python, wheels for these exact versions may not exist yet; use the version above, or relax the pins and expect small numerical differences.

## Inputs that are not in this bundle

The primary datasets are third-party and are downloaded, not redistributed:

- Absolut! binary and per-antigen tables: <https://greifflab.org/absolut/>
- open-alphaseq affinity measurements: <https://huggingface.co/datasets/aalphabio/open-alphaseq>
- AlphaBind campaign measurements: <https://github.com/A-Alpha-Bio/alphabind>
- c-Met panning reads: BioProject PRJNA607865

The Absolut! binary runs under Linux only; on Windows it links and then crashes while reading structure files.
