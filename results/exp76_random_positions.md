## 판정

| 항원 | k=15 → 11 → 8 | k가 줄며 단조 증가 |
|---|---|---|
| 1ADQ_A | 0.805 → 0.826 → 0.828 | 예 |
| 1NCA_N | 0.880 → 0.895 → 0.903 | 예 |
| 1OSP_O | 0.872 → 0.891 → 0.889 | 아니오 |
| 1ZTX_E | 0.945 → 0.960 → 0.973 | 예 |
| 2DD8_S | 0.787 → 0.811 → 0.834 | 예 |
| 2Q8A_A | 0.858 → 0.892 → 0.915 | 예 |
| 3VRL_C | 0.887 → 0.889 → 0.907 | 예 |

7개 항원 가운데 단조 증가는 6개다.

단조성은 중간점 k=11까지 순서를 요구하므로 주장보다 엄격하다. 주장이 기대는 비교는 양 끝 하나다.

양 끝만 보면 7/7개 항원에서 올라간다.

자리 수를 줄이면 같은 크기·조성에서도 라이브러리가 더 학습하기 쉬워진다. 15자리에서 8자리로 가며 평균 +0.031이고, 7개 항원 모두 같은 방향이다.

중간점까지 순서가 맞는 것은 6/7이다. 어긋나는 항원의 차이는 뽑기 간 표준편차(0.023)보다 작으므로 순서를 뒤집을 만한 크기가 아니지만, 양 끝만 보고하면 중간이 흔들린다는 사실이 가려지므로 함께 적는다.

여기에 두 가지 단서를 달아야 한다.

첫째, 크기가 작다. 뽑기마다의 표준편차가 평균 0.023이므로 항원 하나만 놓고 보면 결론이 나지 않는다. 모든 항원이 같은 방향이라는 것이 근거이고, 부호 검정으로는 p = 0.008다.

둘째, 이 크기로는 격자와 실측의 간극을 설명하지 못한다. exp73에서 격자 팔의 대리 적합도는 0.84~0.92, 실측 팔은 0.47~0.69로 차이가 0.2~0.4인데, 자리 수를 절반으로 줄여 얻는 것은 +0.031이다(두 수치는 라벨 수와 라이브러리 크기가 달라 직접 빼서는 안 되고, 자릿수만 비교한다). 차원은 방향이 맞지만 한 자릿수 부족하다. 나머지는 이 논문이 따로 잰 측정 잡음(Spearman 비용 0.105) 쪽에 있을 것이고, 그 둘을 합쳐도 전부를 메우는지는 여기서 답하지 않는다.
