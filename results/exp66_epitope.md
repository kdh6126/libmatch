# exp66 에피토프 대조 — 격자가 천연 항체를 실제 자리에 놓는가

천연 항체의 격자 자세가 닿은 항원 잔기를, 원본 결정 구조에서 그 항체와 4.5A 안에 있던 잔기와 비교했다. 같은 항원에서 무작위 무린 서열 200개의 자세가 만드는 겹침을 비교 집합으로 쓴다. 겹침은 작은 정수라 동점을 절반으로 센다.

| 통계 | 값 |
|---|---|
| 항원 | 90 |
| 천연 겹침 중앙값 | 2.0잔기 |
| 무작위 겹침 중앙값 | 1.70잔기 |
| 결정 에피토프 크기 중앙값 | 20잔기 |
| 백분위 중앙값 | 50.0% |
| 사분위 | 42.3% ~ 54.9% |
| 상위 10% 안 | 8 / 90 |

## 자리가 서열에 따라 달라지는가

격자는 에너지가 가장 좋은 자세를 고르므로, 서열이 무엇이든 항원에서 가장 끈적한 자리로 갈 수 있다. 그러면 위의 백분위가 무엇이 나오든 "격자는 항체가 아니라 항원으로 자리를 정한다"로 읽어야 한다.

| 통계 | 값 |
|---|---|
| 무작위-무작위 접촉 Jaccard 중앙값 | 0.786 |
| 천연-무작위 접촉 Jaccard 중앙값 | 0.795 |
| 5% 이상이 닿은 잔기 중앙값 | 26 |
| 항원 잔기 수 중앙값 | 180 |
| 무작위 평균 겹침이 0.5 미만인 항원 | 32 / 90 |

두 Jaccard가 거의 같다. 무작위 서열끼리도, 천연과 무작위 사이도 접촉 자리가 80%쯤 겹친다 -- 서열이 달라도 격자는 항원의 같은 자리에 붙이고, 천연만 다른 곳으로 가는 것이 아니다. 자리를 정하는 것은 항체가 아니라 항원의 모양이다.

## 검정 — KS의 유의성을 신호로 읽으면 안 된다

| 검정 | 값 |
|---|---|
| 균등성 KS | D=0.277, p=1.28e-06 |
| 백분위가 정확히 50.0%인 항원 | 18 / 90 |
| 50% 미만 / 초과 | 35 / 37 |
| 부호 검정 (동점 제외) | p=0.906 |

KS가 균등분포를 기각하지만 방향이 반대다. 기각의 원인은 천연이 앞쪽으로 쏠린 것이 아니라 백분위가 50% 근처에 **지나치게 몰린** 것이다. 겹침이 작은 정수라 동점이 쏟아지고, 특히 천연도 무작위도 에피토프에 전혀 닿지 않는 항원에서는 전원이 동점이라 백분위가 정확히 50.0%로 찍힌다. 균등분포라면 0~100%에 고루 퍼져야 한다.

방향을 묻는 것은 부호 검정이고, 그쪽은 유의하지 않다. 즉 천연 항체의 격자 자세가 실제 에피토프에 더 잘 닿는다는 증거는 없다.
